# Correo Rápido · Sitio web

Página de inicio y política de privacidad de **Correo Rápido**, una extensión de navegador para ver tus correos de Gmail sin abrir la pestaña de Gmail.

- 🌐 **Página de inicio:** [flavio6931.github.io/correo-rapido](https://flavio6931.github.io/correo-rapido/)
- 🔒 **Política de privacidad:** [flavio6931.github.io/correo-rapido/privacidad.html](https://flavio6931.github.io/correo-rapido/privacidad.html)

## Qué hace la extensión

- Muestra tus correos **recibidos** y **enviados** en un popup.
- Filtros rápidos por fecha: **hoy**, **ayer**, **últimos 7 días**, todo o un **día concreto**.
- Cuenta cuántos correos hay en cada filtro (por ejemplo, "12 correos enviados hoy").
- Buscador con la misma sintaxis que Gmail y lectura del correo dentro del popup.
- **Solo lectura** y **sin servidores**: los correos van directamente de Google a tu navegador.
- Funciona en Chrome, Brave, Edge y Opera.

## Este repositorio

Contiene solo las páginas públicas que Google y la Chrome Web Store piden para publicar la extensión. El código de la extensión está en un repositorio aparte.

```
index.html        página de inicio
privacidad.html   política de privacidad
style.css         estilos (modo claro y oscuro)
icon-128.png      icono de la extensión
```

Se publica con GitHub Pages en `flavio6931.github.io/correo-rapido/`.
